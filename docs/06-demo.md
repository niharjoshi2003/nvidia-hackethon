# Demo script

Target length: under 3 minutes. Public YouTube. Voiceover has to mention Nebius Token Factory and NVIDIA Nemotron by name.

Record the product, not a slide deck. One topic, two sessions.

## Shot list

1. **0:00–0:20.** Home. Say the problem in one line: the drill used to trust a self-rating, so it never heard what you skipped.
2. **0:20–0:45.** Open one real topic from the library. Flash the model answer and one gotcha so the rubric is visible.
3. **0:45–1:20.** Speak a deliberately incomplete 60-second answer. Leave out the gotcha you just showed.
4. **1:20–2:00.** Debrief. Point at two labels: Nano structured the transcript, Ultra named the miss. Read the quote and the rubric line. This is the Token Factory call.
5. **2:00–2:30.** Reload. Home now leads with that topic because the miss is open. Open it and show the same miss before the timer.
6. **2:30–3:00.** One sentence on where data lives (this machine) and the agreement count from the week-3 check, if you have it.

## Lines that have to be said

- “The grade runs on NVIDIA Nemotron through Nebius Token Factory.”
- “Nano only extracts which points were covered. Ultra decides the miss.”
- “We kept the recording and the miss log locally.”

## Do not show

- A chat box with a generic study tip
- Topic generation through OpenAI or Anthropic
- A second feature (Tavily, badges, dashboard charts) unless the miss story is already clear
